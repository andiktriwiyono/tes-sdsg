## 🎯 Fitur Laporan

### Jenis Laporan
1. **Laporan Harian** - Total siswa, sudah test, belum test
2. **Laporan Per Sesi** - Progress per sesi (1, 2, 3)
3. **Laporan Per Meja** - Statistik per meja penguji
4. **Laporan Durasi** - 5 tercepat & 5 terlama
5. **Detail Siswa** - Tabel lengkap semua siswa

### Fitur Export
- ✅ Export Excel (.xlsx)
- ✅ 3 sheets: Summary, Per Sesi, Detail Siswa
- ✅ Formatting otomatis
- ✅ Filter data

### Fitur Print
- ✅ Print-friendly format
- ✅ Auto page breaks
- ✅ Header & footer

### Filter & Sorting
- ✅ Filter per sesi (1, 2, 3)
- ✅ Filter gender (L/P)
- ✅ Filter status test
- ✅ Sort by nama, nomor, durasi

## 🚀 Quick Start

### Akses Laporan
```
1. Login sebagai admin atau role yang punya akses
2. Klik menu "Laporan" di navbar
3. Lihat statistik & data
```

### Export Excel
```
1. Buka halaman laporan
2. Klik tombol "Export Excel"
3. File .xlsx akan terdownload
```

### Print Laporan
```
1. Buka halaman laporan
2. Klik tombol "Print"
3. Dialog print browser akan muncul
4. Pilih printer atau Save as PDF
```
